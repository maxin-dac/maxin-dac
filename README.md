## 🚀 Featured Projects

### 🌍 Global Economic Intelligence Dashboard

An interactive, **bilingual (EN/FR)** platform analyzing **217 countries** across **25 years (2000–2024)** through **58 World Bank indicators**, structured around the **PESTEL** framework. Seven coordinated views — world map, trends & correlations, country profiles, comparison, economic structure, data explorer — plus a dedicated **investment-intelligence module**: composite attractiveness score (0–100), risk/return matrix, and a red-flag detector.

🔗 [**Live Demo**](https://world-bi-dashboard.streamlit.app/) · [**Repository**](https://github.com/maxin-dac/world-economic-dashboard)
